# 極座標カレンダー (Polar Calendar Japan)

日本各地の天体（太陽・月・二十八宿）、潮汐（満潮・干潮）、気象（降水量）、旧暦・暦注、行事、俳句を同心円（極座標）上に美しく可視化するWebアプリケーションです。

---

## 🌟 主な特徴

- **極座標表現 (Polar Coordinates)**: 1朔望月（約29.53日）を360°の円周上に120分割（1セグメント＝6時間）で配置。
- **高精度天文学計算**: Jean Meeus の天体アルゴリズムと SunCalc の数理モデルに基づき、太陽・月の黄経、月齢・月相（新月・上弦・満月・下弦）、日の出・日の入り、月の出・月の入りをリアルタイム計算。
- **二十八宿・天体帯**: 27宿/28宿の天文学的境界と星座マークを外周トラックに動的描画。
- **全国241地点の潮汐・気象連動**: 各観測所の毎時潮位グラフ・降水量グラフ・日別総降水量を円周帯に重ね合わせて可視化。
- **暦注・年中行事・俳句**: Googleスプレッドシート連携による二十四節気・七十二候・祝日・神事・仏事・教会行事・俳句の縦書き表示。
- **インタラクティブ・カスタマイズ**: 全レイヤーの色・透明度・線幅・フォント・オフセットの調整、テーマ保存、セルへのフリーペイント、高解像度PNG出力・印刷機能。

## 🚀 起動方法

### ローカル実行
ブラウザのセキュリティ制限（CORS）のため、ローカルHTTPサーバー経由で開きます。

```bash
# Python を使用する場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。

## 📐 極座標・幾何学仕様

- **中心座標 (`cx`, `cy`)**: `(920.6859, 1191.4759)`
- **1周の総セグメント数 (`TOTAL_SEGMENTS`)**: 120 (30日 × 4セグメント/日)
- **1セグメントの角度 (`DEGREES_PER_SEGMENT`)**: 3° (360° / 120)
- **1日の角度 (`DEGREES_PER_DAY`)**: 12° (3° × 4)
- **1時間の角度 (`DEGREES_PER_HOUR`)**: 0.5° (360° / 720時間)
- **基準日 (`baseDate`)**: 2026年8月13日（新月）
- **平均朔望月 (`synodicMonth`)**: 29.530589日

## ⌨️ ショートカットキー

| キー | 動作 |
| :--- | :--- |
| `Space` (長押し) | 一時的にパン（画面移動）ツールに切り替え |
| `V` | 選択・移動ツール (Pointer) |
| `B` | ペイントブラシツール (Paint) |
| `E` | 消しゴムツール (Erase) |
| マウスホイール | ズームイン / ズームアウト |
| マウスドラッグ (Pointer時) | キャンバスのパン / 回転 |
